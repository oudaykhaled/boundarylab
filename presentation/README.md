# BoundaryLab animated presentation

An eight-scene explanation of the proposed middleware framework, its developer value, real process boundaries, failure semantics and evidence roadmap.

**The animation is illustrative.** The underlying middleware remains unimplemented, with no performance results or external adoption claimed.

## Play

Open `index.html` in a modern browser. The presentation works offline with no package installation, account or network dependency. Start playback with Play; use the visible navigation or keyboard controls to move between scenes. Reduced-motion preferences preserve the content without requiring continuous motion.

The initial PC profile is a macOS JVM host and CLI. The conditional AOSP profile needs separate Linux resources and a booted image. Broker loss invalidates volatile jobs; explicit resubmission starts new work.

[Speaker notes](SPEAKER-NOTES.md) provide a short narrative for each scene. The editable presentation companion lives in the author's Spaces account and has its own access controls; it is not required to play this public browser version.
