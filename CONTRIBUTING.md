# Contributing

This repository currently contains a project plan. Product source and executable lanes will be added only through implementation work. Start with the README and roadmap, select an open planned task, and describe scope and evidence before changing its status.

Use small reviewable changes. Keep protocol changes compatible with the declared support window, include a migration/rejection strategy, and record design tradeoffs. Commit toolchain/dependency pins when executable modules are introduced. Preserve third-party notices; do not add employer code or non-public test data. Use synthetic fixtures only.

Record checks with the exact commit, build and environment. Do not mark native execution or benchmarks passed from source inspection. Discuss differences in platform capability openly; explicit unsupported outcomes are part of the contract. A contributor can reproduce a released sample without disclosing their identity or device serial.

Initial planning was produced using ten independent GPT-6 Astra agent proposals and a coordinating synthesis. The repository maintainer remains responsible for decisions, claims, review and release quality.
